# Infinity Ring · R3 实施计划

依据：brief-and-direction.md；用户已选「可以选择A+C」「我喜欢R3」。按用户指定的创意网站到视频工作流，在三个关键节点 review，不另加计划批准或执行方式问卷。

## 当前范围

先完成本地产品展示站和影片镜头方案。方向是已选的 R3 虹膜结构、A 黑色产品展示、C 自然佩戴场景。公众发布尚未请求，影片须在接受完整网站后制作。浏览器工具当前受自动审批服务容量故障阻断，不能声称已完成视觉 QA。

## 实施顺序

1. 归档 R3 选择；生成同一产品身份的 hero、佩戴、电子工作台、阅读、夜间照明素材。生成图是概念可视化。
2. site/src/content.mjs：12 章文字、导航、组件用途、技术边界与对应资产，内容单一来源。
3. site/src/motion.mjs：连续进度状态、插值、停顿、倒退一致性；显式时间接口留给后续真实站点制片。
4. site/src/ring-model.mjs：可分件的 R3 参数化展示模型。body / liner / rotary bezel / iris leaves / optical windows / electronics / power 分组。无已验证尺寸或装配承诺。
5. site/src/world.mjs：金属环境、模型与相机、目标表面、按状态渲染；无 WebGL 时落到可读静态模式。
6. site/index.html、styles.css、src/app.mjs：主叙事、导航、部件详情、范围和亮度控制、示意语音过程、隐私控制说明、技术说明、可下载简报、手机与减少动效。
7. 静态语法、素材引用、运动连续性和结构检查。真实浏览器滚轮、暂停、倒退、移动端与影片预览等待审批服务恢复后执行，明确保留未验收状态。
8. 收齐站点预览与 QA 后，再推进网站节点。预备约38秒镜头表，重拍实际站点，不用图片幻灯片冒充交互录制。

## 检查重点

- 快速滚动、反向和任意进度的状态确定且无位置突跳。
- 原生滚动保留；导航、返回、键盘、触摸不依赖鼠标专用操作。
- 减少动效或 WebGL 不可用时仍可读全部产品信息。
- 无重叠标题、双环叠影；静态摄影与动态几何的交接需要实际画面验收。
- 不出现假邮箱、假订阅成功、预售承诺、虚构硬件指标或已完成的整机能力。
